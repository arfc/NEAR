# TOD Example
This folder contains the scripts and input files to replicate a profile study of the Cycamore and TOD reactors.

You can run the example from the provided checkpoint with:
```
python extract_time_data.py
```

We have provided the input files and a script to generate all of the profiling data summarized in the given `.csv` files. To run from the very beginning, use:
You can run the example with:
```
bash profile_cycamore_tod.sh
python extract_time_data.py
```
